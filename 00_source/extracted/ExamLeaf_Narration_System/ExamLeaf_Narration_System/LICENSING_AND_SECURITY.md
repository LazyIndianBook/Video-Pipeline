# Rights and security boundaries

The original code and drafted Skills are supplied for ExamLeaf adaptation. No third-party source repositories, model weights, font binaries, performer recordings, credentials, or signed temporary artifact URLs are bundled. Confirm each dependency, chosen model weight and voice licence before commercial use.

Do not run unreviewed curl-pipe-shell installers. Skills are untrusted instruction/code packages, not permission boundaries. Keep model/provider keys only in an allowlisted worker secret store. Research agents and scriptwriters should not have publishing or billing credentials.

All compiled API recipes are non-executing JSON. Replace actual IDs and verify current model contracts before writing a transport. A Runway preset name is not a direct vendor voice ID. Legacy OpenAI recipes are for migration inspection only. Never convert a local audition-only flag into fictional consent.

Cache and hash controls here are local demonstrations. Production requires an authenticated reviewer and approval service, encrypted storage and appropriate privacy/retention controls. Avoid collecting student recordings for voice cloning. Only adult performers who knowingly agree to the exact uses should supply performance or identity references.
