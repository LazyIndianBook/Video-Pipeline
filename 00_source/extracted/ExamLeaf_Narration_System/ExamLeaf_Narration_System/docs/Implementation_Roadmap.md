# Integration roadmap

## Week1: casting and reference contracts
Approve the academic/spoken source pipeline and build12 connected listening passages plus the40 written term entries. Audition3 suitable voices in each needed language using identical content and normalized playback level. Establish actual voice rights and model IDs. Teacher/native reviewers must reject meaning-changing pronunciations regardless of acting preference. Student pilot feedback is usability evidence, not proof of examination gains.

## Week2: one live provider transport
Implement one approved Elevenv4 or Gemini3.8 transport after account access is confirmed. Keep synthesis out of the agent's direct shell. Persist actual request/response format, provider ID and billed usage. Add explicit per-run spending limits, concurrency limits, timeout reconciliation, HTTP error classes and no blind paid retries. Do not use the deprecated OpenAI fixture for new production.

## Week3: independent transcription and real alignment
Add an independent ASR route with verbatim settings where supported. Reject language resources that are unavailable rather than inventing word timing. Import actual forced alignment and verify against a manually annotated sample. English, Hindi and Assamese require separate transcript normalization tests. Manually listen to scientific critical terms and numbers. Test omitted words, repeated phrases, code switching and planned pauses.

## Week4: video integration and full pilots
Feed timeline events to the existing ExamLeaf scene adapters. Let natural narration determine scene duration. Regenerate only affected segments; update hashes and approvals. Complete four genuinely narrated subject pilots, not padded versions of the timing fixtures. Check caption answer leakage, phone readability, joins and final encoded audio.

## Weeks5–6: controlled batch and operations
Run20–30 complete lessons with academic/native-language/final listening approval. Measure accepted audio cost, retake fraction, human minutes and synchronization defects. Add durable queue, authenticated approval service and dashboard only around validated contracts. Expand catalogue when the cost and quality distribution—not just the best demo—are acceptable.

## Staffing and boundaries
Assumes dedicated engineering time and available subject/language reviewers, not an unattended guarantee. Original15 Skills are editorial capabilities/subtasks, not15 parallel paid LLM passes. Preserve existing science review rather than duplicating or replacing it. Maintain a central content corpus, library, model lifecycle ledger and corrections process.
