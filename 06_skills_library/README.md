## How the three packs relate

The packs arrived in this order: **v1 backlog (40, message 02) → Super Teacher (10, message 08) → Video Engine (32, message 10) → Narration (15, message 12).**

1. **The Video Engine 32 are the canonical pipeline-stage skills.** Each one owns one stage output and carries a `Priority` (P0/P1/P2) in `references/contract.md`. Section 6 of message 10 consolidated v1's 40 rows into these 32 and stated the rule **"one Skill owns each output"**.
2. **The Narration 15 are a sidecar that decomposes 8 of the 32.** `configs/existing_engine_skill_mapping.json` assigns each narration skill to exactly one engine parent. Message 12 §5 explains how this works: the engine Super Teacher *delegates* naturalization and delivery preparation, the engine science reviewers stay the authority for the explanation and answer key, the renderer receives measured narration events, and release requires audio-specific approval evidence. In message 12's own words, these are "fifteen capabilities — not fifteen mandatory LLM calls".
3. **The Super Teacher 10 are an earlier standalone authoring kit.** It is script-centric and ships its own `authoring_contract.md`. No mapping file covers it, so this library *proposes* how it relates to the other packs (see `OVERLAP_and_DEDUPLICATION.md`). In short, each ST skill either stands alone for authoring outside the engine, or serves as a reviewer lens. It is never a second author of an output the engine already owns.

## Known gaps (recorded, not fixed)

- **Zero of the 57 are agent-evaluated.** Each has 1 eval (ST) or 1 positive + 1 generic negative (VE/NA). None has the full v1 contract set of "correct + deliberately incorrect + regression fixtures" at skill level. No skill has a `scripts/` folder; VE keeps its deterministic code in shared `src/` by design.
- **Three eval formats.** ST uses the Anthropic skill-creator `evals.json` shape. VE and NA use custom `cases.json` shapes that need converting first (see INSTRUCTIONS §12).
- **The VE descriptions are template-generated and weak triggers.** Each one reads "Use to … in the ExamLeaf pipeline", for example "Use to use relevant stories…". Trigger tests are needed before relying on auto-invocation.
- **Near-duplicate names across packs** can mis-trigger if both are installed: `interaction-design`/`interaction-designer`, `voice-direction`/`voice-director`, `super-teacher`/`super-teacher-scriptwriter`. See `OVERLAP_and_DEDUPLICATION.md`.
- **v1 rows 11 (exam-rubric) and 37 (regression-qa)** have no v2 owner. Row 4 (prerequisite-graph) and row 16 (independent-review) have no dedicated VE owner.
- **No priority is assigned** to the ST or NA skills in their sources.
