## 4. How to change a decision

1. Open a change note citing the AD number, the new evidence and the edge cases affected.
2. If the change touches a project-wide rule (RD-xx), the runbook owner records a new RD entry in `07_end_to_end_pipeline_instructions/10_DECISIONS_and_CONFLICT_RESOLUTIONS.md`; this file then references it.
3. Update the affected docs (00–05 and the companion docs 06–13), the style files, the harness contract and the skills' `evals/cases.json`.
4. Re-run the golden scenes, the determinism test and the relevant negative tests (`12_advanced_animations_with_claude/06_prompts_and_templates/negative_tests.md`); "Upgraded model/voice/library versions cannot pass solely because an earlier version passed" (`07_end_to_end_pipeline_instructions/01_SETUP_new_machine_and_repository.md` §7).
5. Any approval bound to an artefact that changes is invalidated (doc 05 §5.2).
