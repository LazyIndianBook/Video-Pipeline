# Technology decision matrix

> **Section 09 - research and evidence.** Every tool, library, service and provider that ChatGPT's six responses or the delivered packs evaluated, in one place, with the same eight attributes: **recommended role | strength | limitation | licence / pricing as stated | verification level | caveat | source**.
>
> All facts are as stated by the sources, checked **13 October 2026**. **No tool was benchmarked, auditioned or compared head-to-head by ChatGPT**: msg 02 s1 says "Tool rankings are recommendations for your use case - not results of a renderer benchmark or voice audition performed here"; the Cost_and_Skills ReadMe says "No candidate renderer, voice, locale or model was benchmarked or auditioned as part of this report." Prices are planning inputs, not quotes. Where two sources give different numbers both are shown and the conflict is listed in section 11.

## Verification-level vocabulary (used in the "Verification level" column)

| Phrase | Meaning (from the sources) |
|---|---|
| **Implemented and tested (bounded)** | Original code in the Video Engine / Narration pack that was actually run; tests passed (56 and 57 tests respectively). Scope is a bounded fixture, not a production claim. |
| **Executed on fixtures** | A real tool ran on synthetic data (FFmpeg loudnorm on signal fixtures; SoundFile/SciPy on a synthetic timeline). No speech-quality claim. |
| **Live, narrow** | A connected Runway account was used (read-only authentication; one speech job; two Eleven v3 auditions). Outputs were never downloaded or listened to locally. |
| **Documentation inspected; not installed or executed** | The official docs/repo files were read. Nothing installed, run or benchmarked. |
| **Research-read; not live-tested** | Narration directory phrase: "Research-read is not live-tested." |
| **Compiled request recipe only** | The Narration pack builds non-executing request JSON for the provider; zero network requests; production transport not implemented. |
| **Planning input** | A number used in a cost model; either a published tariff or an ExamLeaf assumption. |
